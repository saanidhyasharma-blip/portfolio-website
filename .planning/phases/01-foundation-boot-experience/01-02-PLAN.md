# Plan: 01-02-PLAN.md - Boot Sequence & Initialization

Implement the animated "Initialization" sequence that users see when first entering the site.

## Context

The first impression of this portfolio is a "System Boot" terminal. This plan builds the logic and UI for that sequence, including the "Press Start" gate.

## Tasks

<task id="1">
<read_first>
- .planning/PROJECT.md
</read_first>
<action>
Create a Zustand store in `src/lib/store/useArcadeStore.ts` to manage the "Boot" state:
- `isBooted`: boolean
- `isInitializing`: boolean
- `setBooted(val)`: action
- `setInitializing(val)`: action
</action>
<acceptance_criteria>
- `useArcadeStore.ts` exists and exports the `useArcadeStore` hook.
- Store includes the specified states and actions.
</acceptance_criteria>
</task>

<task id="2">
<read_first>
- src/components/arcade/BootSequence.tsx
</read_first>
<action>
Build the `BootSequence` component in `src/components/arcade/BootSequence.tsx`.
- Use GSAP to animate lines of text simulating a terminal boot:
  - "INITIALIZING SYSTEM..."
  - "LOADING SHADERS..."
  - "MOUNTING CORE..."
  - "PRESS START TO ENTER"
- Once "Start" is pressed, update the Zustand store.
</action>
<acceptance_criteria>
- `BootSequence.tsx` exists.
- Component uses GSAP `Timeline` for sequential text animation.
- A "Start" button appears at the end of the sequence.
</acceptance_criteria>
</task>

<read_first>

Update the main page `src/app/page.tsx` to conditionaly render the `BootSequence`.

</action>
<acceptance_criteria>

</task>
