# Phase 3 Context: Arcade Projects Arena

## Vision
The Projects section should feel like a "Level Select" screen from a retro arcade game. Each project is a "Level" with its own stats, difficulty (complexity), and rewards (tech used).

## Key Features
- **Project Grid**: A scrollable or grid-based layout of "Arcade Cards".
- **Arcade Cards**: Feature pixel-art style thumbnails (or glowing tech icons), project title, and "Level" number.
- **Cinematic Expansion**: Clicking a card triggers a high-impact GSAP animation that expands the card into a full-screen "Project Mission" view.
- **Project Mission View**: Displays full description, live links, GitHub link, and a tech stack breakdown.

## Technical Strategy
- **Zustand**: Manage the selected project state for the expansion animation.
- **GSAP Flip Plugin (or manual scale)**: Handle the smooth expansion from grid card to full view.
- **Framer Motion**: Animate the grid entries and hover states.
