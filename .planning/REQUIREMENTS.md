# Requirements: Saanidhya Sharma's Arcade Portfolio

**Defined:** 2026-05-14
**Core Value:** Delivering a "WOW" experience through immersive, arcade-inspired UI/UX that instantly communicates Saanidhya's technical depth and creativity.

## v1 Requirements

### Core Experience (EXPR)
- [ ] **EXPR-01**: Animated loading sequence with boot-up terminal animation.
- [ ] **EXPR-02**: "Press Start" screen before entering the main site.
- [ ] **EXPR-03**: Keyboard sound effects on interaction (optional/toggleable).
- [ ] **EXPR-04**: Interactive custom cursor with motion trails and hover distortions.
- [ ] **EXPR-05**: Lenis smooth scrolling integration for modern high-end feel.

### Home Page (HOME)
- [ ] **HOME-01**: Hero section with cinematic intro and dynamic background.
- [ ] **HOME-02**: 3D holographic avatar or hologram effect.
- [ ] **HOME-03**: Typing animation for "Building AI-Powered Digital Experiences".
- [ ] **HOME-04**: Interactive CTA buttons with hover effects.

### Projects Arena (PROJ)
- [ ] **PROJ-01**: Display projects as "Arcade Levels" with cinematic expansion.
- [ ] **PROJ-02**: Live tech stack animations on project cards.
- [ ] **PROJ-03**: Glowing borders and 3D transitions for project interaction.
- [ ] **PROJ-04**: Filtering system for project categories (AI/ML, Full Stack, etc.).

### GitHub Arena (GITA)
- [ ] **GITA-01**: Live GitHub API integration fetching repositories.
- [ ] **GITA-02**: Contribution heatmap visualization.
- [ ] **GITA-03**: Language distribution charts and commit activity tracking.
- [ ] **GITA-04**: Repository search and animated expansion.

### Skills & Experience (SKEX)
- [ ] **SKEX-01**: Arcade inventory system for skills with animated progress meters.
- [ ] **SKEX-02**: Hover tooltips and "Unlock" effects for skills.
- [ ] **SKEX-03**: Animated timeline for career progression (Rigel, AWS, Deloitte).
- [ ] **SKEX-04**: Story-based journey section for "About".

### Contact & Social (CONT)
- [ ] **CONT-01**: Interactive terminal contact form.
- [ ] **CONT-02**: Animated communication panel for social links.
- [ ] **CONT-03**: Floating neon buttons for email interactions.

### Design & Polish (DSGN)
- [ ] **DSGN-01**: CRT distortion and scanline overlay effects.
- [ ] **DSGN-02**: Pixel-inspired UI mixed with modern glassmorphism.
- [ ] **DSGN-03**: Magnetic hover effects and smooth page transitions.
- [ ] **DSGN-04**: Dynamic lighting based on mouse position.

## v2 Requirements

### Advanced Interactivity
- **ADV-01**: AI Chatbot Assistant for site navigation.
- **ADV-02**: Retro mini-game embedded in a hidden page.
- **ADV-03**: Unlockable UI themes (different arcade styles).
